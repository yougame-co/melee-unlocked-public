# Melee Unlocked: YouGame's version

This is YouGame's build of **Melee Unlocked**, Hero's native PC version of Super Smash Bros. Melee (NTSC 1.02).
Melee Unlocked is Hero's work, together with its contributors: <https://github.com/Hero88go/melee-unlocked>.
This repository is YouGame's version of it: the same game, plus YouGame online play (sign-in and online
matches through the YouGame app) and fixes for starting it on its own.

## You need your own Melee disc

No game files are included here or in any download. You need your own copy of Super Smash Bros. Melee, NTSC
version 1.02 (game ID GALE01), as an `.iso` disc image.

## Play it

- **Windows:** download the zip from [Releases](https://github.com/yougame-co/melee-unlocked-public/releases),
  unzip it, and double-click `melee_source.exe`. The first start asks for your Melee disc and remembers it.
- **In the YouGame app (public beta):** <https://staging.yougame.co>. The app starts the game, signs you in and
  finds you online matches.

## Problems and ideas

Please open an [issue here](https://github.com/yougame-co/melee-unlocked-public/issues). This build differs from
the original, so please don't report its problems to the original Melee Unlocked project.

## Source

Each commit here is the full source of one YouGame build. `YOUGAME.md` says which build it is and what it changes;
`BUILDING.md` explains how to build it. The original Melee Unlocked README is in `docs/UPSTREAM_README.md`.
